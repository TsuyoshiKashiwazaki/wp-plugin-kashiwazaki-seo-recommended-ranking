投稿・固定ページ・カスタム投稿に、おすすめランキングを挿入できるプラグインです。ランキングの一元管理と、本文上下への自動挿入・ショートコードによる手動挿入に対応します。

== Description ==

Kashiwazaki SEO Recommended Ranking は、「〇〇のおすすめランキング」を記事とは別に作っておき、いくつもの記事で使い回せるプラグインです。ランキングを更新すると、そのランキングを表示しているすべてのページに反映されます。

= 主な機能 =

* **ランキングの一元管理** … 管理画面でランキングごとに作成・編集・複製・削除できます。
* **見出しと概要説明** … ランキングの見出し（h2・h3・h4・太字の文字・表示しない）と、見出しの下の説明文を設定できます。
* **3位〜10位** … 1位〜3位から、最大1位〜10位まで。各順位に名称・簡単な説明・URL を入力します。
* **並べ替え** … 順位の追加・削除と、ドラッグや矢印のボタンでの並べ替え。
* **入力中のプレビュー** … PC・スマホの幅で、保存前の見た目と構造化データを確認できます。
* **表示するランキングの選択** … 投稿・固定ページ・カスタム投稿の編集画面で、表示するランキングと表示位置（本文の上・本文の下・手動・表示しない）を選べます。
* **ショートコード** … 手動のときは `[kashiwazaki_seo_recommended_ranking]` を本文の好きな位置に書きます。`[kashiwazaki_seo_recommended_ranking id="123"]` で、ほかのランキングも表示できます。
* **リンクの設定** … ボタンの文言、新しいタブで開く、外部リンクの rel（nofollow・sponsored）。
* **5 つのデザインの型** … スタンダード・王冠・シンプル・比較表・上位3つを大きく。設定画面で既定の型を選び（見本でその場で見比べられます）、ランキングごとに変えることもできます。
* **スマホでも見やすいデザイン** … 置いた場所の幅に合わせて形が変わります。1位〜3位の金・銀・銅、メインの色の変更、文字の色の自動調整。
* **構造化データ** … ItemList・ListItem・Recommendation を基本に、おすすめする対象の種類（指定しない・商品・サービス）と、Guide でのまとめを選べます。

= 動作対象 =

公開ページでは、ランキングを表示するページだけでスタイルを読み込みます。スクリプトは使いません。

== Installation ==

1. プラグインのフォルダ `wp-plugin-kashiwazaki-seo-recommended-ranking` を `wp-content/plugins/` に配置するか、ZIP を「プラグインのアップロード」からインストールします。
2. 「プラグイン」から「Kashiwazaki SEO Recommended Ranking」を有効化します。
3. 左メニューの「Kashiwazaki SEO Recommended Ranking」を開き、見出しの横の「ランキングを新規作成」で、ランキングを作って公開します。画面の上のタブで「ランキング一覧」と「設定」を行き来できます。
4. 投稿・固定ページの編集画面の「Kashiwazaki SEO Recommended Ranking」のボックスで、表示するランキングと表示位置を選びます。

== Frequently Asked Questions ==

= ランキングが表示されません =

ランキングが「公開」になっているか、ページの編集画面で表示位置が「表示しない」になっていないかを確かめてください。下書き・非公開・パスワード保護のランキングは表示されません。設定画面の「ランキングを選べる投稿タイプ」に、その投稿タイプが入っているかも確かめてください。

= 公開ボタンを押しても下書きのままです =

公開するには、3位までの名称が必要です。名称が空のまま説明や URL だけを入力した順位があるときも公開できません。

= ショートコードとボックスの両方で同じランキングを選ぶとどうなりますか？ =

同じページの本文に同じランキングのショートコードがあるときは、ショートコードの位置にだけ表示します（2回は表示しません）。

= 構造化データで Google のリッチリザルトは出ますか？ =

ItemList・Recommendation は、Google のリッチリザルトの対象ではありません。検索エンジンやAIに、ランキングの中身と順位を正しく伝えるためのものです。

= プラグインを削除するとデータはどうなりますか？ =

既定では、ランキングと各ページの選択は残ります。設定画面で「削除するときに…削除する」を選んだときだけ、すべて消します。
